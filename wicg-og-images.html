WICG OG share images

When someone shares a link to your site or an article on Facebook, Twitter, LinkedIn, iMessage, Slack, Discord, or any modern platform, this is the image that shows in the link preview card. All images are 1200×630 pixels (the universal OG standard). Save each one, upload to your GitHub repo root, and the <meta property="og:image"> tag in each page's head will pull from it automatically.

How to deploy these images

Step 1: Right-click each SVG below and save it. (If your browser saves them as SVG, you'll convert to PNG in step 2.)

Step 2: Go to cloudconvert.com or svgtopng.com. Upload each SVG and export as PNG at the dimensions shown (1200×630). Keep the exact filenames listed below each image.

Step 3: Push all 6 PNG files to the root of your GitHub repo (same folder as index.html).

Step 4: Verify the <meta property="og:image"> tag in each article's HTML head matches the filename. They already do based on the article files I built. Test by pasting a URL into opengraph.xyz or Facebook's Sharing Debugger.

Final deployment checklist

  1. Right-click each SVG above, "Save Image As"
  2. Convert each to 1200×630 PNG via cloudconvert.com
  3. Rename them to the exact filenames listed under each image
  4. Upload all 6 files to the root of your GitHub repo (next to index.html)
  5. Commit and push
  6. Wait 2-3 minutes for GitHub Pages to deploy
  7. Test at opengraph.xyz: paste each URL one at a time, confirm the correct image loads
  8. Test on Facebook directly: paste womenincryptoglobal.com/first-100-crypto.html into a private message draft, verify the preview card shows correctly

If Facebook caches an old version (no image), use Facebook's Sharing Debugger at developers.facebook.com/tools/debug/ and click "Scrape Again" to force a refresh.
